# Team Contributions

## Project
**AI-Powered Resume Analyzer and Career Assistant (ResumeAI)**

This project was developed as a collaborative team effort. Each team member contributed to different aspects of the system based on their assigned responsibilities.

---

# Team Members and Contributions

## 1. K Adithya Sankar (Team Head)
**Role:** Team Lead & Backend Developer

### Responsibilities
- Led the complete project development and coordinated the team.
- Designed the overall system architecture.
- Planned and managed the backend workflow.
- Developed the entire backend using **Python** and **FastAPI**.
- Integrated the **Groq AI API** for AI-powered resume analysis and generation.
- Implemented REST APIs for:
  - Resume Upload
  - Resume Analysis
  - Resume Improvement
  - AI Resume Builder
  - Interview Question Generation
  - Job Matching
  - Applied Jobs Tracking
- Developed resume parsing modules for PDF and DOCX files.
- Implemented ATS analysis logic.
- Designed the database structure using **SQLite** and **SQLAlchemy**.
- Created backend services for AI communication and document processing.
- Managed environment configuration and API integration.
- Performed backend testing, debugging, and optimization.
- Oversaw integration between frontend and backend.
- Finalized project architecture and overall functionality.
